# Material para publicar TL;DR.ai

Textos listos para copiar en la Chrome Web Store, en tu sitio web o en el panel de privacidad. **Sustituye** los marcadores `[TU_...]` (URL de política, contacto, etc.) antes de publicar.

| Archivo | Uso |
|--------|-----|
| [privacy-policy-en.md](./privacy-policy-en.md) | Política de privacidad (inglés); suele alojarse en una URL pública. |
| [privacy-policy-es.md](./privacy-policy-es.md) | Misma política en español. |
| [store-listing-en.md](./store-listing-en.md) | Nombre, descripciones y notas para la ficha en inglés. |
| [store-listing-es.md](./store-listing-es.md) | Ficha en español. |
| [permissions-and-data-disclosure.md](./permissions-and-data-disclosure.md) | Texto para el cuestionario de permisos y datos del desarrollador (EN/ES). |
| [checklist.md](./checklist.md) | Pasos antes de enviar el ZIP a revisión. |

Versión de extensión referenciada: **1.0** (ajusta si cambias `manifest.json`).
