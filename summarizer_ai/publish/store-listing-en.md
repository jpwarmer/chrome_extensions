## Detailed description

**TL;DR.ai** helps you read faster: one click to get a **structured summary**, a **critical analysis** (bias, tone, misinformation hints), and a **comments overview** when the page has comment-like sections.

**Highlights**
- Works on the **page you’re viewing** — no separate dashboard.
- **Multiple AI backends**: Google **Gemini**, **OpenAI** (GPT-3.5), **Anthropic Claude** — you add **your own API keys** in the extension.
- **English & Spanish** UI.
- **Local cache** of the last result per page and model (optional convenience).
- **Floating button** + clean **modal** so you stay in context.

**Privacy-first by design**: API keys and cached results stay in your browser’s local storage. Text you analyze is sent **only** to the AI provider you choose, under **their** terms.

**Note:** You need an API key from at least one supported provider. Costs and quotas follow each provider’s pricing.
